Android Backup
==============

The interface uses English text in this preview release. Built-in WinUI
language and satellite resource folders (en-US, id-ID when supplied by
Windows) are stored alongside the real WinUI executable under App/.
They are required by the Windows resource loader and are NOT relocated.

This Language folder is for user-facing documentation and future app-owned
translations. Changing files here does not currently translate the UI.
