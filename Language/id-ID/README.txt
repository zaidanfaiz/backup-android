Android Backup
==============

Antarmuka versi pratinjau masih menggunakan bahasa Inggris. Folder resource
bahasa milik WinUI dan Windows tetap berada di samping AndroidBackup.exe
internal, yaitu dalam App/, karena diperlukan saat pemuatan resource.

Folder Language ini ditujukan untuk dokumentasi pengguna dan paket terjemahan
aplikasi di versi mendatang. Mengubah berkas di sini belum mengubah bahasa UI.
